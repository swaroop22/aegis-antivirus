Quick Installation

Up and guarding your machine in under 60 seconds.

🍎 MACBOOK INSTALLATION
  1. Download the Aegis-Defender-Pro-macOS.dmg installer.
  2. Open the DMG and drag Aegis Defender Pro.app into your Applications folder.
  3. Launch the App: Double-click to start real-time protection in a dedicated desktop window.
🪟 WINDOWS INSTALLATION
  1. Download the Aegis-Defender-Setup.exe installer.
  2. Run the Setup Wizard: Installs Aegis Defender and creates a Desktop shortcut automatically.
  3. Launch the App: Double-click the shortcut to arm the shield with zero terminal clutter.

Developer Command-Line Quickstart

Prefer running from source? Clone and launch in one command:

git clone https://github.com/swaroop22/aegis-antivirus.git && cd aegis-antivirus && ./run.sh
